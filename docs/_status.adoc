= Status

Checked against Nix 2.34.9 and nixpkgs `31ecbaca1bde` on x86_64-linux.

Language tests::
graalnix passes NixOS/nix's `tests/functional/lang` suite (303 tests) and
Tvix's `eval/src/tests/tvix_tests`, apart from the cases listed with reasons in
`language/src/test/java/lang-skip.txt`.

Top-level packages::
For every top-level nixpkgs attribute (`scripts/toplevel-drvpaths.nix`),
graalnix and `nix-instantiate` produce 24,268 identical drvPaths. 680 attributes
fail in both, and none differ or fail in only one evaluator. The run takes
1 min 40 s on the JVM, against 2 min 08 s for Nix.

Heavier attributes::
`scripts/parity.sh` finds identical drvPaths for `firefox`, `chromium`,
`libreoffice`, `texliveFull`, `haskellPackages.pandoc`, `nixosTests.firefox`,
`pkgsCross.aarch64-multiplatform.hello` and `pkgsStatic.hello`.

== Not supported

* Fetchers (`fetchurl`, `fetchTarball`, `fetchGit`, `fetchTree`) and flakes.
* Import from derivation.
* Content-addressed and impure derivations.
* `--xml` output.
* The `--lint-*` flags.
* Rejection of NUL bytes in strings, and UTF-8 validation in `toJSON`.
