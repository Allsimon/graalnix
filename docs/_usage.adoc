= Getting started

Build it with Nix, either on the JVM or as a static native binary (linked
against musl), which starts in milliseconds rather than half a second:

[source,sh]
----
nix build .#graalnix          # on OpenJDK 25
nix build .#graalnix-native   # native image, built with GraalVM
----

To format and lint only, `graalnix-lite` and `graalnix-lite-native` provide a
`graalnix` command with only `format`, `check` and `fix`, without the evaluator
and Truffle.

Each package installs bash and zsh completions; `graalnix generate-completion`
prints the script, to source in a shell where it is not installed.

To try the formatter and linter in a browser, build the playground and open
its page; they run in the page, compiled to JavaScript:

[source,sh]
----
nix build .#playground && xdg-open result/index.html
----

Evaluate an expression:

[source,console]
----
$ ./result/bin/graalnix eval --strict -E 'builtins.map (x: x * 2) [ 1 2 3 ]'
[ 2 4 6 ]
----

Compute the derivation path of a nixpkgs attribute:

[source,sh]
----
./result/bin/graalnix drv-path -I nixpkgs=/path/to/nixpkgs -E 'import <nixpkgs> {}' -A hello
----
