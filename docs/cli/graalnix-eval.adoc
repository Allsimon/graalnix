== Description

Evaluate an expression and print the result, like nix-instantiate --eval.

// end::picocli-generated-man-section-description[]

// tag::picocli-generated-man-section-options[]
== Options

*-A*, *--attr*=_ATTR_::
  Select an attribute path in the result.

*--arg*=_NAME EXPR_::
  Call a function result with NAME bound to EXPR.

*--argstr*=_NAME VALUE_::
  Call a function result with NAME bound to the string VALUE.

*-E*, *--expr*=_EXPR_::
  Evaluate EXPR.

*-h*, *--help*::
  Show this help and exit.

*-I*, *--include*=_PATH_::
  Add an entry to the search path of lookups such as <nixpkgs>, as nixpkgs=/path/to/nixpkgs; the entries of NIX_PATH come after.

*--json*::
  Print the result as JSON.

*--raw*::
  Print a string result without quotes or escapes.

*--show-trace*::
  Print the Nix call stack when the evaluation fails.

*--strict*::
  Force the result deeply before printing it.

*--system*=_SYS_::
  Set builtins.currentSystem.

// end::picocli-generated-man-section-options[]

==  Engine options

[%hardbreaks]
Any other --name or --name=value option goes to the GraalVM polyglot engine, as name=true or name=value. This includes the language's own --nix.* options and the Truffle tools, such as --inspect for the Chrome DevTools debugger and --cpusampler to profile the evaluation.

[%hardbreaks]
Runtime compilation is off by default: on nixpkgs it made evaluations 4 to 10% slower for 1.5 times the CPU and memory. --engine.Compilation=true turns it back on.
