==  Files

[%hardbreaks]
Files are read as UTF-8, and one that is not is refused. A file is written only when its content changes. A file that fails is reported on standard error, and the other files are still processed. Each file rewritten is named on standard error, then a count of the files changed, unchanged and failed, and the time taken.

[%hardbreaks]
This follows the treefmt formatter spec:
https://treefmt.com/latest/reference/formatter-spec/
