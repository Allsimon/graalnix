= graalnix
:toc: left
:toclevels: 2
:sectanchors:
:source-highlighter: rouge
:icons: font

graalnix is an implementation of the Nix language on GraalVM, as a Truffle AST
interpreter. It evaluates nixpkgs unmodified and computes store paths and `.drv`
paths in memory, without writing anything to `/nix/store`.
